# UNES University

A simple three-page institutional website built for **UNES University**, structured entirely with semantic HTML tables and lightly styled using internal CSS (`<style>`).

## Project Overview

This project showcases a classic table-based page layout architecture alongside a functional contact form. It consists of three interconnected HTML pages:

- **Home (`index.html`):** Main landing page featuring the university's cover banner, welcome message, and general overview.
- **About Us (`about-us.html`):** Institutional page detailing the university's history, mission, values, and academic structure.
- **Contact (`contact.html`):** Contact page containing an interactive form for visitors to get in touch.

## Tech Stack

- **HTML5:**
  - Full-page layout built using the `<table>` element, organized semantically into `<thead>`, `<tbody>`, and `<tfoot>` sections with `<tr>` and `<td>` cells.
- **CSS3:**
  - Lightweight internal styling applied via the `<style>` tag within each HTML document for basic spacing and alignment.

## Getting Started

1. Clone or download this repository to your local machine.
```bash
git clone https://github.com/HarllonCS/unes-university.git
```

2. Open the `index.html` file in any web browser.

3. Use the top navigation bar to switch between **Home**, **About us**, and **Contact**.
